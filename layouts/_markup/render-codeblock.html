Every fenced block gets a header bar — language icon and label on the left, copy-to-clipboard button on the right — above the highlighted code. The label shows, in order: the file name, the free title, the language. Info string — Chroma options (lineNos, hl_lines, lineNoStart, style, tabWidth, anchorLineNos...) are passed through to Hugo's highlighter untouched, the same options the highlight shortcode accepts. Examples: python fence with {filename="hello.py"} js fence with {filename="app.js" copy=false} bash fence with {title="Install" icon=false} Per-block extras (they override the site defaults): filename="hello.py" label as a file name (wins over title) title="Install" free label icon=true|false|"python" language icon / off / explicit icon copy=true|false copy button Site defaults (config/_default/params.yaml) — both on by default: code: icon: true language icon — false to disable copy: true copy button — false to disable icons: language → icon mapping overrides vue: nuxt styles: Chroma palette pair — see highlight.html light: friendly dark: dracula A block that asks for nothing — both site defaults at false and no filename, title, icon or copy in the info string — is rendered the native way: the same wrapping div and highlighted pre Hugo emits on its own, rebuilt around the highlight function. The four attributes this hook consumes (title, filename, icon, copy) are never re-emitted as HTML attributes, and a class attribute is merged into the element class instead of a duplicate attribute. Syntax colors come from the Chroma palettes linked by layouts/_partials/highlight.html (markup.highlight.noClasses: false). The header carries the chroma class too, so it shares the palette background and text color of the code — one unified block, in light and dark mode alike, whatever the Chroma style.
